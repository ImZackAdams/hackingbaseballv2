# GlassBoxMLB OddsEdge v1 Spec (Flask)

## Goal
Build a Flask MVP that shows MLB game predictions, best sportsbook odds, and EV/edge per market.

## Must-haves
- Dashboard page with today's games.
- Results/report page with:
  - Model win probabilities (home/away).
  - Best odds by sportsbook (moneyline).
  - EV per side, derived from model probability.
- $1 Stripe checkout for a report (no per-game pricing).
- No bet placement.

## Non-goals
- Scraping sportsbook websites.
- In-app betting.

## Data sources
- MLB schedule from MLB Stats API (via statsapi).
- Odds: mock or cached data acceptable for v1.

## Stop condition
- All tests pass.
